# SciCalc - Scientific Calculator (Python Tkinter)

A small scientific calculator with a graphical interface.

## Run
1. Install Python 3 (Tkinter comes with it).
2. Open a terminal in this folder and run:

       python scicalc.py

## Features
- Basic: + - * / and brackets
- Scientific: sin, cos, tan (degrees), log (base 10), ln, sqrt, ^ (power), fact (factorial), pi, e
- C = clear, DEL = delete last character, Enter key = equals
- Shows "Error" for invalid input (e.g. 10/0) instead of crashing

## Demo examples
| Type this | Result |
|---|---|
| 5+3*2 | 11 |
| 2^10 | 1024 |
| sqrt(144) | 12.0 |
| sin(30) | 0.5 |
| log(100) | 2.0 |
| fact(5) | 120 |
| sin(30)+sqrt(16)*2^3 | 32.5 |
| 10/0 | Error |
